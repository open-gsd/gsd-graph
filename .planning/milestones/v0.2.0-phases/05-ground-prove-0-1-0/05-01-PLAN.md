  <action>
    Implement the thinnest vertical pack slice: types + packSubgraph happy path over public query ops (per D-01, D-02, D-10, D-11, D-12).

    1. Add types in src/types.ts (shapes from DESIGN / RESEARCH Pattern 5):
       - SubgraphPack: question, seeds: string[], nodes, triples, paths (same shape as QueryPath), citations array of { triple_id, s, p, o, source_path? }, trimmed: string | null, budget_tokens: number | null
       - PackOptions: question: string, dir?, graph?: GraphV1Document, hops?, kSeeds?, budget?: number | null
       - Export types from index alongside packSubgraph

       Defaults: hops = DEFAULT_SEED_HOPS (2), kSeeds = 5, budget = opts.budget ?? null.
       Load graph: if opts.graph defined use it; else loadGraphV1(resolveStoreRoot({ dir: opts.dir }) or default) — same pattern as loadQueryGraph in query.ts (D-10).

    3. Algorithm (D-02) — composition only (D-01 / PACK-01):
       - Tokenize question: NFKC/lower, split on non-alphanumeric, drop PACK_STOPWORDS, keep tokens length ≥ 2. Export PACK_STOPWORDS as the exact DESIGN set: a, an, the, and, or, of, to, in, on, for, why, how, what, is, are, did, does, do (no extras in 0.1.0 per RESEARCH OQ-R2).
       - Score each node (NFKC-lower label/description/aliases): token full substring of label +3; of description +1; of any alias +2. Sum per node.
       - seeds = top kSeeds by score descending; drop score 0; ties: shorter label length then id ascending. Keep seed id list.
       - buildAdjacencyMap(graph). For each seed id: expandHops(adj, graph, Set([id]), hops) OR query({ graph, id, hops }) — union node ids and triple ids. Prefer expand-by-id (D-02 pitfall 3: do not call seedAndExpand(label) for expansion).
       - If ≥2 seeds: among top min(3, seeds.length) pairs, materialize path via query({ graph, path: { from, to, maxDepth: hops + 2 } }) (strongest D-01) or findShortestPath + consistent triple materialization; union paths and path triples. Prefer fewest-edge path when multiple exist for the same pair.
       - applyBudget(nodes, triples, budget, seedIdSet); set trimmed and budget_tokens from result.
       - citations = remaining triples mapped to { triple_id: t.id, s, p, o, source_path: first provenance source_path if present }.
       - If no triples after union/budget: return pack with empty nodes/triples/paths/citations arrays (do not throw GraphError EMPTY_SUBGRAPH — empty is a valid pack; answer abstains in plan 05-02).

    4. Export packSubgraph and PACK_STOPWORDS from src/index.ts public façade.

    5. tests/pack-answer.test.ts (node:test, D-12): require dist/index.js after build. Prefer building a temp store from only tests/fixtures/corpus/multi-hop.jsonl via init+build, or construct/load graph via loadGraphV1 after isolated build. Assert multi-hop question yields paths with causes and citations ⊆ triple ids. Cover opts.graph in-memory path.

    Avoid: private BFS/dijkstra in pack.ts; reading graph.json; LLM; answer() (plan 05-02); CLI (plan 05-03).
  </action>
