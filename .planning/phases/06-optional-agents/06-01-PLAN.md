## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Host / operator → prompt result files | Untrusted LLM or human-filled JSON enters store and apply path |
| Process → optional HTTP LLM endpoint | Network egress only when mode=http + explicit config/flag |
| Prompt templates → model | Corpus/question content may be sent when operator enables LLM |
